# Business Insights Dashboard – Power BI Project

This Power BI dashboard provides insightful visualizations and analysis of business sales, profits, and performance across various segments. The goal is to empower decision-makers with a clear, interactive view of key metrics.

## 🧠 Features

- Total Sales & Profit KPIs
- Category & Sub-category wise performance
- Regional trends and loss analysis
- Discount impact on profitability
- Slicers for dynamic filtering
- Drill-down capabilities

## 📂 File

- `bussiness-insights.pbix`: Power BI report file

## 💡 Skills Used

- Power BI
- Data Cleaning (Power Query)
- Dashboard Design
- Data Visualization
- Exploratory Data Analysis

## 🚀 How to Use

1. Download the `.pbix` file.
2. Open in Power BI Desktop.
3. Explore filters, slicers, and charts to understand business performance insights.
